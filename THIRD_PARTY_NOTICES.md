# Third-party notices

Z-MarkDowner bundles the following open-source components in `Resources/Web`. Their license texts are included next to the files.

| Component | Version | License | Files |
|:--|:--|:--|:--|
| [KaTeX](https://github.com/KaTeX/KaTeX) | 0.16.22 | MIT | `Resources/Web/katex/` (`LICENSE`) |
| [Mermaid](https://github.com/mermaid-js/mermaid) | 11.4.1 | MIT | `Resources/Web/mermaid/` (`LICENSE`) |

Self-contained HTML exports reference the same versions from the jsDelivr CDN when a document contains formulas or diagrams.
